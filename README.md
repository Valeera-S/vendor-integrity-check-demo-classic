# Vendor Integrity Check, demo site (classic look)

A static copy of the Vendor Integrity Check web form exactly as it looks when run locally, built by the Vanderbilt AI-CPS Lab for the NYC Department of Design and Construction's Responsibility Determination process. A restyled version of the same cases is at https://valeera-s.github.io/vendor-integrity-check-demo/.

Every case on the site is a recorded run of the research tool against public NYS, NYC and federal records on the date shown. Nothing is searched live here, and uploads on manual steps are not saved. This is a research prototype and not an official City of New York service.

Site: https://valeera-s.github.io/vendor-integrity-check-demo-classic/

This repository holds only the generated files; it is rebuilt from the tool's source repository with `scripts/publish_site.ps1 -Theme classic`.
